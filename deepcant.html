Can't Stop

Juego de dados para 2 jugadores · en línea

Ingrese su nombre y un código para empezar.
Cómo se juega
  • Hay 11 columnas (2 a 12) con distinta altura. Se tiran 4 dados y se forman 2 parejas: se obtienen 2 sumas por combinación.
  • Se avanzan hasta 3 corredores temporales por turno. Si no se puede avanzar con ninguna suma, se pasa y se pierde todo lo temporal.
  • Después de cada avance se elige Seguir (tirar de nuevo) o Plantarse (fijar el avance).
  • Al llegar a la cima de una columna, esa columna se cierra para ambos. Gana quien cierre 3 columnas.
  • Cada jugador tiene su propio progreso en cada columna: se avanza desde la propia ficha más alta.
